
##### FLUXO FALA

1.  USUARIO FALA OU DIGITA
2. BOCA OUVE RESPONDE SUPERFICIALMENTE (COM O CONTEXTO DOS ULTIMOS 15 MINUTOS) (MENOS DE 1S DE ESPERA)
3. CEREBRO OUVE (NO MESMO INSTANTE QUE A BOCA), VERIFICA SE TEM FERRAMENTAS/GATES PRA USAR (MANDA PRO ORQUESTRADOR CASO RECONHECA ALGO EXECUTAVEL), SE TEM MEMORIA PRA CARREGAR E CARREGA
4. BOCA RESPONDE (CONFORME O CEREBRO FOR MANDANDO INFORMACOES)
5. CEREBRO ABRE UM NOVO QODER/PROCESSO E TRABALHA NAQUILO CASO NAO FOR APENAS UMA PERGUNTA DE TEXTO


#### FLUXO EXECUCAO
1. CEREBRO IDENTIFICA EXECUCAO
2. OQUESTRADOR MANDA PRO GATE CORRETO
3. ORQUESTRADOR NOTIFICA CEREBRO
4. CEREBRO MANDA PRA BOCA
5. BOCA RESPONDE


#### FLUXO RESPOSTA
1. CEREBRO IDENTIFICA CONTEXTO (BUSCA MEMORIA)
2. CEREBRO SUGERE COISAS COM BASE NO CONTEXTO OU RESPONDE UMA PERGUNTA DIRETA E MANDA PRA BOCA
3. BOCA FALA 

#### FLUXO TRABALHO
1. USUARIO CONFIRMA "ATUACAO/EXECUCAO"
2. CEREBRO CRIA UM PLANO DE ACAO E INFORMA PARA A BOCA
3. BOCA INFORMA AO USUARIO
4. USUARIO SOLICITA ABERTURA NA TELA (OBSIDIAN)
5. USUARIO APROVA O PLANO (CONFIRMACAO DE IDENTIDADE VIA SENHA NO TEXTO OU CONFIRMACAO DE VOZ)
6. CEREBRO CRIA UM QODER/PROCESSO PARA EXECUTAR E NOTIFICA A BOCA A CADA MUDANÇA
7. BOCA ATUALIZA O USUARIO


### FLUXO MAPEAMENTO WHATSAPP
1. OBSERVADOR VERIFICA NOME DE PERSONAS NO WHATSAPP OU MENSAGEM DIRETA NO WHATS ATRIBUIDO PARA A PERSONA (CASO NAO TENHA O NOME É PARA A BOCA/CEREBRO, CASO TENHA O NOME TEM QUE MANDAR PROS 2 E PARA A PERSONA)
2. BOCA E CEREBRO RECEBEM MENSAGEM COM NOME
3. EXECUTA O FLUXO DA FALA
